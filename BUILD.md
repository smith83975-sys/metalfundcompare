# MetalFund Compare
Live: https://smith83975-sys.github.io/metalfundcompare/ (GitHub Pages, gh-pages branch). Static build output goes to `site/`.

## One-command update (not scheduled yet)
    cd /workspace/metalfund && .venv/bin/python update.py
Fetches Nasdaq daily prices (~75 calls, 1.2 s apart), plus about 15 issuer pages/files (Sprott, iShares JSON, SSGA XLSX, Aberdeen, U.S. Global, Y'all Street). Raw responses are cached in `raw/daily/<date>/`. Then it appends `data/discount_history.csv`, writes `data/live.json` and rebuilds `site/`.
Options: `--no-prices`, `--offline` (rebuild from today's cache), `--tickers=GLD,SLV`.

## Rebuild only
    .venv/bin/python build_site.py      # METALFUND_SITE_URL / METALFUND_BASE_PATH override the GitHub Pages defaults

## Publish (GitHub Pages)
    ./publish.sh        # rebuild + force-push site/ to the gh-pages branch (run after update.py)

## Local preview
    METALFUND_BASE_PATH= .venv/bin/python build_site.py && python3 -m http.server 8080 --bind 127.0.0.1 --directory site   → http://127.0.0.1:8080/
    (root-path build for local viewing; run build_site.py again without the variable before publishing)
    python3 shots.py                                                 → shots/*.png

## Files
- `funds.json`/`funds.csv` (generated by `build_funds.py`, which includes the 2026-10-16 verification overrides), `sec_fees.py` (SEC fee lookup)
- `update.py`, `build_site.py`, `templates/`, `static/`, `data/` (prices, nav, live.json, discount_history.csv)
